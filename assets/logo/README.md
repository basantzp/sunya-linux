# Sunya Linux Logo

## Logo Design
The Sunya Linux logo combines:
- **Full citrus slice** (left): Represents completeness and open source
- **Half citrus slice** (right): Represents simplicity and minimalism
- **Lime green (#A6E22E)**: Fresh, fast, performance
- **Charcoal outline (#25272A)**: Professional, solid foundation

## Usage
- **SVG**: `sunya-linux-logo.svg` (scalable, all sizes)
- **Colors**: Lime green + charcoal
- **License**: GPL-3.0 (same as Sunya Linux)
